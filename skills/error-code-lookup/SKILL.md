# 错误码速查

1. 用户给出错误码时，在下表中找到对应行，按「处理建议」回答，并说明能否直接重试。
2. 只有报错信息、没有错误码时，按「含义」匹配最接近的 1 到 3 条，说明匹配依据，请用户确认。
3. 表中查不到的错误码，直接说明查不到，建议用户带上 request_id 联系值班，不要猜测含义。
4. 回答时附上 HTTP 状态码，方便用户对照网关日志。

错误码格式为 `<服务前缀>-<四位数字>`：1xxx 资源类、2xxx 参数类、3xxx 系统类、4xxx 鉴权类、5xxx 异步任务类。

| AUTH-4006 | 账号已被冻结 | 风控冻结或欠费 | 联系客服解冻 | 403 | 否 |
| AUTH-4007 | 需要二次验证 | 敏感操作要求短信或 TOTP 验证 | 完成二次验证后重新提交 | 403 | 否 |
| AUTH-4008 | 跨租户访问被拒绝 | 令牌所属租户与资源租户不一致 | 切换到正确的租户后再操作 | 403 | 否 |
