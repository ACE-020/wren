# 查询业务指标

1. 先和用户确认三件事：指标名称、时间范围、对比基准（环比、同比，或与某个版本对比）。
2. 指标口径以数据团队的指标文档为准。用户给了文档链接时用 `fetch_url` 读取；没给时先问，不要按常识猜口径。
3. 用 `run_sql` 查询数据仓库。只写 `SELECT`，查询必须带时间范围条件，并加 `LIMIT 1000`。
4. 回答分三部分：
   - **数值**：查询结果和对比基准，写清楚口径与时间范围；
   - **变化**：涨跌幅，超过 ±10% 的单独标出；
   - **可能原因**：只列数据能支持的推断，并说明还需要哪些数据才能确认。
5. 查询失败或没有权限时，把 SQL 和报错原样告诉用户，不要编造数字。
