# 写周报

1. 先读 `references/template.md`，严格按其中的结构和顺序输出，不增删一级小节。
2. 如果用户没给出本周日期范围，用 `current_time` 工具确认今天的日期，按「本周一至今天」计算。
3. 用户给的信息不足以填满某个小节时，在该小节写「（待补充）」，并在周报最后用一句话列出需要用户补充的内容。不要编造工作内容或数据。
4. 每条工作用「动词开头 + 结果」的写法，例如「完成登录页联调，修复 3 个问题」，不要写「在做登录页」。
5. 「下周计划」最多 5 条，按优先级排序。
6. 整份周报控制在 400 字以内；用户要求「更短」时只保留「本周完成」和「下周计划」两节，每节最多 3 条。
