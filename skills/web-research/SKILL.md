# 网页调研

1. 用户给了网址时，用 `fetch_url` 读取原文；没给网址时，先告诉用户你需要从哪些网站查证，请用户提供或确认网址，不要凭记忆编造链接。
2. 每读完一个页面，先提取与问题直接相关的事实，忽略导航、广告和无关段落。
3. 最终回答的结构：
   - **结论**：一到三句话。
   - **依据**：逐条列出事实，每条后面用 `[n]` 标注来源。
   - **来源**：编号列表，每条包含页面标题和网址。
4. 不同来源说法冲突时，把冲突写出来，并说明你更相信哪一个以及原因。
5. 页面读取失败（超时、跳转、非文本内容）时如实告诉用户，不要假装已经读过。
