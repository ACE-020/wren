# 技术文档写作规范

## 1. 语气

- 用「你」称呼读者，用主动语态。
- 一句话只说一件事；超过 40 字的句子拆开写。
- 不用「简单地」「只需」「显然」这类词。读者觉得不简单时，这些词只会让人更沮丧。

## 2. 中英文混排

- 中文与英文、数字之间加一个空格：「运行 3 次」「打开 GitHub」。
- 中文句子用全角标点；代码和命令里的标点保持半角。
- 数字一律用阿拉伯数字。

## 3. 术语与格式

- 产品名和专有名词的写法以 `references/terms.md` 为准，首次出现时可以在括号里附英文原名。
- 界面上的按钮、菜单名用「」括起来：点击「保存」。
- 文件名、命令、配置项、代码标识符用行内代码：`config.yaml`。
- 重要概念第一次出现时加粗，之后不再加粗。

## 4. 标题

- 标题不加句号，不超过 20 字。
- 最多用到三级标题。
