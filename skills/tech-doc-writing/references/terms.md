# 术语表

写法以本表为准。术语在正文中的排版（什么时候加粗、什么时候用行内代码）见 `references/style.md` 第 3 节。

| 推荐写法 | 不要写成 | 说明 |
|---|---|---|
| GitHub | github、Github | |
| JavaScript | javascript、Javascript | 正式文档中不要缩写成 JS |
| Node.js | nodejs、NodeJS | |
| Python | python | 命令行里的 `python` 除外 |
| API key | apikey、API Key、api-key | |
| 登录 | 登陆 | |
| 账号 | 帐号 | |
| 回合 | 轮次 | 一条用户消息，加上 agent 为它产生的全部回复 |
| 会话 | 对话框 | 界面左侧列表中的一项 |
| 工具 | 插件 | agent 可以调用的能力 |
| 部署 | 布署 | |
| 配置项 | 配置参数、设置项 | 写进配置文件的键 |
